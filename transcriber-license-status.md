# transcriber license status

Show whether this copy is licensed.

## Synopsis

```
transcriber license status [options]
```

## Description

Unlicensed copies transcribe only the first 45 seconds of each media (exit 10) and refuse segment transcription (exit 77). Licensing is managed by FxFactory.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
