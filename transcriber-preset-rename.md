# transcriber preset rename

Rename a preset.

## Synopsis

```
transcriber preset rename [options] <name> <new-name>
```

## Arguments

- `<name>`: Preset name.
- `<new-name>`: New name.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
