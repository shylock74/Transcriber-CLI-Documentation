# transcriber contexts tokens

Estimated tokens of contexts, against the AI model's budget.

## Synopsis

```
transcriber contexts tokens [options] [<context>...]
```

## Description

Without arguments: the contexts enabled by default.

## Arguments

- `<context>...`: Contexts (default: the enabled ones). Optional.

## Options

- `--doc <document>`: Use this document's selection.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
