# transcriber dictionaries remove-item

Remove an item (by number or id; see 'dictionaries show').

## Synopsis

```
transcriber dictionaries remove-item [options] <dictionary> <item>
```

## Arguments

- `<dictionary>`: Dictionary: name, number or id.
- `<item>`: Item number or id.

## Options

- `--dry-run`: Show what would change; write nothing.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
