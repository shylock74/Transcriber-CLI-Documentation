# transcriber ai metadata sets

List the prompt sets of the library and their prompts.

## Synopsis

```
transcriber ai metadata sets [options]
```

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
