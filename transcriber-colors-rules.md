# transcriber colors rules

Automatic rules: a word or phrase always gets a color.

## Synopsis

```
transcriber colors rules <command> [options]
```

## Commands

- [`list`](transcriber-colors-rules-list.md): Show the rules.
- [`add`](transcriber-colors-rules-add.md): Color every occurrence of a word or phrase (whole words, any case).
- [`remove`](transcriber-colors-rules-remove.md): Delete a rule (by text, number or id).
- [`enable`](transcriber-colors-rules-enable.md): Turn a rule on.
- [`disable`](transcriber-colors-rules-disable.md): Turn a rule off (kept).
