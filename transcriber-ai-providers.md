# transcriber ai providers

List the AI providers, the selected one, and where each key comes from.

## Synopsis

```
transcriber ai providers [options]
```

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
