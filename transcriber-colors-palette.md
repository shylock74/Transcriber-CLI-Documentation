# transcriber colors palette

List and edit the palette.

## Synopsis

```
transcriber colors palette <command> [options]
```

## Commands

- [`list`](transcriber-colors-palette-list.md): Show the palette.
- [`add`](transcriber-colors-palette-add.md): Add a color.
- [`set`](transcriber-colors-palette-set.md): Rename or recolor a palette entry.
- [`remove`](transcriber-colors-palette-remove.md): Remove a color and the rules that use it.
- [`reset`](transcriber-colors-palette-reset.md): Restore the default palette (Yellow, Cyan, Green, Orange, Red); keeps rules whose color survives.
