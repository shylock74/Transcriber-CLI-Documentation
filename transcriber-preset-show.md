# transcriber preset show

Show a preset's settings (by default those that differ from the factory defaults).

## Synopsis

```
transcriber preset show [options] <name> [<key>]
```

## Arguments

- `<name>`: Preset name.
- `<key>`: A section or key. Optional.

## Options

- `--all`: Every setting, not only the changed ones.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
