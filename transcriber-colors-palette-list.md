# transcriber colors palette list

Show the palette.

## Synopsis

```
transcriber colors palette list [options] [<document>]
```

## Arguments

- `<document>`: Transcriber document (omit with --app). Optional.

## Options

- `--app`: Work on the app's defaults (the palette and rules new documents start from).

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
