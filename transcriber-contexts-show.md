# transcriber contexts show

Print a context's content on stdout (--info for its details instead).

## Synopsis

```
transcriber contexts show [options] <context>
```

## Description

Examples:

```
transcriber contexts show "Product names"
```

 transcriber contexts show 2

```
    --info
```

## Arguments

- `<context>`: Context: name, id or number.

## Options

- `--info`: Show the details, not the content.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
