# transcriber models list

List the models, their size and whether they are installed.

## Synopsis

```
transcriber models list [options]
```

## Description

The default model is the one in the app's settings (or --preset/--config/--set).

## Options

- `--installed`: Only the installed models.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
