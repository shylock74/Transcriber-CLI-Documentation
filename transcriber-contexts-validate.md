# transcriber contexts validate

Check that YAML contexts parse and list entities.

## Synopsis

```
transcriber contexts validate [options] [<context>...]
```

## Arguments

- `<context>...`: Contexts (default: every YAML one). Optional.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
