# transcriber preset delete

Delete a preset (asks first; --yes skips).

## Synopsis

```
transcriber preset delete [options] <name>
```

## Arguments

- `<name>`: Preset name.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
