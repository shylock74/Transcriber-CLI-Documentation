# transcriber batch queue list

List the queue: status, media, duration, destinations.

## Synopsis

```
transcriber batch queue list [options]
```

## Options

- `--paths`: Show the document and output paths.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
