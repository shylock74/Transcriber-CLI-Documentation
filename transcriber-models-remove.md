# transcriber models remove

Delete downloaded models to free disk space (asks first; --yes skips).

## Synopsis

```
transcriber models remove [options] [<model>...]
```

## Arguments

- `<model>...`: Models: small, medium, large-v2, large-v3, large-v3-turbo, parakeet. Optional.

## Options

- `--all`: Every model.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
