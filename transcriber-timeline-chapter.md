# transcriber timeline chapter

Chapters in a timeline: add, rename, remove (export as titles in the FCPXML).

## Synopsis

```
transcriber timeline chapter <command> [options]
```

## Commands

- [`add`](transcriber-timeline-chapter-add.md): Insert a chapter before a sentence.
- [`rename`](transcriber-timeline-chapter-rename.md): Rename a chapter.
- [`remove`](transcriber-timeline-chapter-remove.md): Remove chapters (all with --all; the sentences stay).
