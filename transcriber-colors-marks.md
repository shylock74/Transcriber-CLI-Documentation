# transcriber colors marks

Manual marks: one word of one subtitle gets a color (documents only).

## Synopsis

```
transcriber colors marks <command> [options]
```

## Commands

- [`list`](transcriber-colors-marks-list.md): Show the colored words (marks and rules) of a track.
- [`set`](transcriber-colors-marks-set.md): Color a word in subtitles ('none' removes a rule's color there).
- [`clear`](transcriber-colors-marks-clear.md): Remove manual marks (rules stay).
