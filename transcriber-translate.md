# transcriber translate

Translate a document's subtitles with DeepL into new translation tracks.

## Synopsis

```
transcriber translate <command> [options]
```

## Commands

- [`run`](transcriber-translate-run.md): Translate into one or more languages (one new track each).
- [`languages`](transcriber-translate-languages.md): List DeepL's target languages (codes for --to).
