# transcriber models path

Print the folder of the models (or the file of one model).

## Synopsis

```
transcriber models path [options] [<model>]
```

## Arguments

- `<model>`: A model (optional). Optional.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
