# transcriber contexts duplicate

Duplicate a context ("<name> Copy", or --name).

## Synopsis

```
transcriber contexts duplicate [options] <context>
```

## Arguments

- `<context>`: Context: name, id or number.

## Options

- `--name <name>`: Name of the copy.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
