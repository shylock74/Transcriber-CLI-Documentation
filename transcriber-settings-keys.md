# transcriber settings keys

List every settings key with its type and current value.

## Synopsis

```
transcriber settings keys [options] [<prefix>]
```

## Description

Example:

```
transcriber settings keys srtSettings
```

## Arguments

- `<prefix>`: Only keys under this prefix. Optional.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
