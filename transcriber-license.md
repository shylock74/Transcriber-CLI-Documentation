# transcriber license

Show the licence state (FxFactory) or open FxFactory to buy / unlock.

## Synopsis

```
transcriber license <command> [options]
```

## Commands

- [`status`](transcriber-license-status.md): Show whether this copy is licensed.
- [`unlock`](transcriber-license-unlock.md): Open FxFactory on Transcriber's page to buy or unlock it.
