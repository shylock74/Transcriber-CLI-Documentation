# transcriber keys list

Show which providers have a key, and where it comes from (keys are masked).

## Synopsis

```
transcriber keys list [options]
```

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
