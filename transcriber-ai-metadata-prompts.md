# transcriber ai metadata prompts

List the prompts of the library (shared with the app).

## Synopsis

```
transcriber ai metadata prompts [options]
```

## Options

- `--search <text>`: Only prompts whose name or description contains this.
- `--full`: Print each prompt's full text.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
