# transcriber doc settings

A document's own settings: show, set, unset, apply, diff.

## Synopsis

```
transcriber doc settings <command> [options]
```

## Description

Same keys as 'transcriber settings' (see 'transcriber settings keys').

## Commands

- [`show`](transcriber-doc-settings-show.md): Show the document's settings (all, a section, or one key).
- [`set`](transcriber-doc-settings-set.md): Change the document's settings: key=value pairs.
- [`unset`](transcriber-doc-settings-unset.md): Put document settings back to the factory value.
- [`apply`](transcriber-doc-settings-apply.md): Replace the document's settings with the app settings, a preset or a settings file.
- [`diff`](transcriber-doc-settings-diff.md): Compare the document's settings with the app settings (or another source).
