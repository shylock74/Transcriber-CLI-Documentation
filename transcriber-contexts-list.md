# transcriber contexts list

List the contexts: number, format, language, tokens, enabled.

## Synopsis

```
transcriber contexts list [options]
```

## Options

- `--enabled`: Only the enabled ones.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
