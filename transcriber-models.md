# transcriber models

List, download and remove the Whisper models.

## Synopsis

```
transcriber models <command> [options]
```

## Commands

- [`list`](transcriber-models-list.md): List the models, their size and whether they are installed.
- [`download`](transcriber-models-download.md): Download models (resumes nothing: a failed download starts over).
- [`remove`](transcriber-models-remove.md): Delete downloaded models to free disk space (asks first; --yes skips).
- [`path`](transcriber-models-path.md): Print the folder of the models (or the file of one model).
