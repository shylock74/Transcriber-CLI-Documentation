# transcriber ai models

List the text models of a provider (ids for --model).

## Synopsis

```
transcriber ai models [options] [<provider>]
```

## Description

Example:

```
transcriber ai models anthropic
```

## Arguments

- `<provider>`: Provider (default: the selected one): gemini, openai, anthropic, deepseek, local. Optional.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
