# transcriber speakers

List, rename and assign speakers.

## Synopsis

```
transcriber speakers <command> [options]
```

## Description

Speakers come from imported subtitles ('ANNA: …' or [Anna]) or are set here; exports can include them.

## Commands

- [`list`](transcriber-speakers-list.md): Speakers with subtitle counts and speaking time.
- [`rename`](transcriber-speakers-rename.md): Rename a speaker everywhere (every track).
- [`set`](transcriber-speakers-set.md): Assign a speaker to subtitles.
