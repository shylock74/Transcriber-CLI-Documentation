# transcriber contexts language

Set a context's reference language (BCP-47 such as it-IT, or 'auto').

## Synopsis

```
transcriber contexts language [options] <context> <code>
```

## Arguments

- `<context>`: Context: name, id or number.
- `<code>`: Language code or 'auto'.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
