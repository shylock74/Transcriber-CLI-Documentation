# transcriber subs split-long

Split subtitles that do not fit in max lines × max characters per line.

## Synopsis

```
transcriber subs split-long [options] <document>
```

## Description

Limits come from the document (srtSettings.maxCharPerLine / maxLines) unless given.

## Arguments

- `<document>`: Transcriber document (.transcriber), or - for stdin.

## Options

- `-t, --track <track>`: Track: 'source' (default), or a translation's id, language code or title. Default: `source`.
- `--max-chars <N>`: Characters per line.
- `--max-lines <N>`: Lines per subtitle.
- `-o, --output <path>`: Write the document here instead of in place ('-' = stdout).
- `--dry-run`: Show what would change; write nothing.
- `--backup`: Copy the document to <name>.transcriber.bak before writing it.
- `--force`: Write even if the document is open in Transcriber, or the output exists.

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
