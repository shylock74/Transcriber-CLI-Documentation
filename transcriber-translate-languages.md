# transcriber translate languages

List DeepL's target languages (codes for --to).

## Synopsis

```
transcriber translate languages [options]
```

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
