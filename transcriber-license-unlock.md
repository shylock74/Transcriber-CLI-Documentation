# transcriber license unlock

Open FxFactory on Transcriber's page to buy or unlock it.

## Synopsis

```
transcriber license unlock [options]
```

## Global options

Every command also accepts the [global options](global-options.md): `--json`, `--progress`, `-q`, `-v`, `--no-color`, `--log-file`, `-y`, `--no-input`, `--config`, `--preset` and `--set`.
